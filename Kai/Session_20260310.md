## BUG FIXED: POST /api/posts PERMISSION_DENIED

### Root Cause
`createPost()` trong `lib/firebase.ts` dùng **client Firestore SDK**.
API route chạy server-side không có auth token → Firestore security rules từ chối.
Lỗi: `PERMISSION_DENIED: Missing or insufficient permissions`

### Fix Applied
`app/api/posts/route.ts` — thay `createPost` (client SDK) bằng **Admin Firestore**:
- Import `getAdminFirestore` từ `lib/firebase-admin`
- Import `FieldValue` từ `firebase-admin/firestore`
- Gọi `adminDb.collection('posts').add(...)` trực tiếp
- Admin SDK bypass Firestore rules hoàn toàn

### Files Changed
- `app/api/posts/route.ts` — committed & deployed
